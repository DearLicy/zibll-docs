Skill 文档用于把项目内的开发资料整理成 AI 更容易执行的任务说明。它不替代源码阅读，也不提供远程执行能力，而是把常见任务的入口、约束和验证方式写清楚，减少重复解释。

## 适合沉淀的内容

- 源码目录和关键模块的定位方式。
- 插件、子主题、部署和主题扩展文档的阅读顺序。
- 常见任务的实现边界，例如不改主题核心文件、优先使用 Hook。
- 验证步骤，例如构建、类型检查、接口抽样和浏览器检查。

## 与 MCP 的关系

MCP 服务负责把文档资源暴露给 AI 客户端；Skill 文档负责说明如何使用这些资源完成任务。需要读取全文或搜索页面时，优先使用 [MCP 服务器](/docs/mcp) 中的资源入口。
