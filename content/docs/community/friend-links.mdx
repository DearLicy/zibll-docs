本站友情链接页用于收录与 WordPress、子比主题、插件、开发者工具或独立站建设相关的项目。当前页面内容由仓库中的 `data/friends.json` 静态生成，不读取远程站点列表，也不需要本站账号。

## 申请信息

请准备以下内容：

| 字段     | 说明                                | 是否必填 |
| -------- | ----------------------------------- | -------- |
| 名称     | 网站或项目名称                      | 是       |
| 网址     | 可正常访问的 `http` 或 `https` 地址 | 是       |
| 介绍     | 一到两句话说明网站或项目内容        | 是       |
| Logo     | 可公开访问的图片地址                | 否       |
| 联系邮箱 | 用于审核沟通                        | 否       |
| 回链地址 | 放置本站链接的页面                  | 否       |

请在 [友情链接页面](/friends) 填写信息。页面会在浏览器中生成友情链接 Issue 并打开 GitHub，不会把表单内容保存到本站服务器或本地数据库；这是与文档反馈不同的公开审核流程。

GitHub Issue 是公开页面，名称、网址、介绍、Logo、联系邮箱和回链都会出现在申请记录中。不希望公开邮箱时请留空，或只填写专门用于公开联系的地址。合并后的 `data/friends.json` 只保存名称、网址、介绍、Logo 和推荐状态，联系邮箱与回链不会进入站点数据或构建产物。

## 审核流程

1. GitHub Issue 模板收集申请信息。
2. 自动工作流检查网址、字段长度、重复链接和基本格式；编辑 Issue 后会重新校验并更新同一条待审核 PR。
3. 通过格式检查后生成待维护者审核的 Pull Request。
4. 维护者确认网站内容、可访问性和回链情况后再合并。
5. 合并后重新构建静态站，友情链接卡片和多语言页面同步更新。

自动校验通过不等于最终收录。恶意跳转、自动下载、违法违规、与主题和开发者社区无关或无法长期访问的站点不会收录。
