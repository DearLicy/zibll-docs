欢迎通过公开渠道交流子比主题、WordPress、插件、子主题和本项目文档。社区交流是经验分享渠道，不是付费技术支持或代开发服务。

## 先使用公开资料

提问前请先：

1. 搜索本站文档和 GitHub Issues。
2. 写明主题、子主题、插件、PHP 和 WordPress 版本。
3. 贴出最小复现步骤、报错原文和已经尝试过的方案。
4. 删除 API Key、登录 Cookie、数据库密码、用户隐私和生产环境敏感地址。

能形成可复用结论的文档问题，优先使用文档页底部反馈，由 GitHub Bot 创建带页面上下文的 Issue；其他协作问题可以直接提交 [Issue](https://github.com/DearLicy/zibll-docs/issues)，这样后续用户也能搜索到答案。

## QQ 群交流规则

- 讨论应围绕 WordPress、子比主题开发、本项目文档、MCP、Codex 插件和合法的站点工程问题。
- 群主和管理员没有义务为每个成员提供一对一技术支持，也不承诺解决第三方主题、插件或上游服务的问题。
- 不发布账号交易、密钥交易、恶意代码、未授权数据、诱导下载、刷屏广告或违法违规内容。
- 涉及上游服务时，应遵守上游服务条款、平台规则和适用法律法规。
- 需要可追踪的修复、功能建议或文档变更时，请回到 GitHub Issue / Pull Request，不要只在群聊中留下结论。
