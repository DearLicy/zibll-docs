`llms.txt` 是面向 AI 客户端的文档索引。它用纯文本列出本站文档结构、页面地址和 Markdown 入口，让 AI 更容易知道应该读取哪些资料。

和 MCP 不同，`llms.txt` 不需要客户端支持协议。你可以直接把链接发给 AI，或者让支持读取 URL 的工具先读取索引，再按需读取单篇文档。

## 适合的场景

- 让 AI 快速了解本站有哪些文档。
- 给不支持 MCP 的客户端提供文档上下文。
- 把某一篇文档作为 Markdown 资料发给 AI。
- 在提问前先让 AI 读取文档索引，减少答非所问。
