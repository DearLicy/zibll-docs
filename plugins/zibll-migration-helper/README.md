# 子比迁移整理助手

这是子比主题开发文档的迁移整理专业 Codex 插件，适合旧站迁移、Zibpay 下载资源、媒体路径、域名替换、文章内容和字段清理。

## 安装

```bash
codex plugin add zibll-migration-helper@zibll-docs
```

如果还没有添加本站插件市场，先运行：

```bash
codex plugin marketplace add https://github.com/DearLicy/zibll-docs.git
```

## 适合场景

- 迁移旧 WordPress 文章、媒体、附件和下载资源。
- 整理 Zibpay 付费下载、资源链接和商品字段。
- 做域名替换、对象存储路径迁移、CDN 路径检查。
- 清理旧短代码、旧下载块、坏链和内容结构。
- 尽量保持文章发布时间、更新时间和业务字段不被误改。
