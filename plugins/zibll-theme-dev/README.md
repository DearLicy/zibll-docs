# 子比主题二开助手

这是子比主题开发文档的专业 Codex 插件，适合插件、子主题、Hook、Ajax、Meta、模板覆盖和 Codestar Framework 二开任务。

## 安装

```bash
codex plugin add zibll-theme-dev@zibll-docs
```

如果还没有添加本站插件市场，先运行：

```bash
codex plugin marketplace add https://github.com/DearLicy/zibll-docs.git
```

## 适合场景

- 开发独立的子比主题扩展插件。
- 制作子主题和模板覆盖。
- 查找 Hook、Filter、Ajax、短代码和主题函数。
- 编写 Codestar 设置项、文章 Meta、小工具和字段读取逻辑。
- 判断功能应该放在插件、子主题还是现有扩展点。
